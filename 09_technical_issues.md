# Technical Issues
For technical problems, collect the relevant error message and basic troubleshooting details.
If documented troubleshooting does not resolve the issue, escalate it.

## Information to collect
- The exact error message
- What the user was doing when it happened
- Device, browser or app version
- When it started, and whether it happens every time
- Which troubleshooting steps were already tried

If the documented troubleshooting does not resolve the issue, escalate it with this information attached.

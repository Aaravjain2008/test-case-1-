# Contributing

1. Fork the repository and create a branch from `main`.
2. Keep each pull request focused on one change.
3. For knowledge-base articles, keep the short style of the existing files: a `#` title and a few plain sentences.
4. If you change `search_engine.py`, run the tests: `python -m unittest discover -s tests`.
5. Open a pull request with a short description of what changed and why.

Never include real passwords, API keys or personal data in articles or examples.

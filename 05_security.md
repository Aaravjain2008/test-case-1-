# Security
Security incidents should be treated as high priority.
Requests involving suspected account compromise, stolen credentials, or unauthorized access should be escalated.

## Examples
- The user reports a login from an unknown location: treat it as suspected account compromise and escalate.
- The user says their credentials were stolen: escalate as high priority.

## What to include when escalating
- A way to identify the account
- When the suspicious activity was noticed
- What the user observed
- A short justification for the escalation

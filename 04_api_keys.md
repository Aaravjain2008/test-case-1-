# API Keys
API keys should be kept private and never posted in public messages.
If a key may have been exposed, the user should rotate it and follow the account security process.

## Examples
- A user pastes a full API key in a public message: tell them to rotate the key right away and follow the account security process.
- A user asks where to find their key: guide them to the documented location and never ask them to paste the key back.
- A key may have been committed to a public repository: treat it as exposed and advise rotation.

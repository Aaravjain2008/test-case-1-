# Glossary

**Escalation** - handing a ticket to a specialised team because it cannot be resolved from the knowledge base.

**Knowledge base** - the markdown articles in this repository that support answers are based on.

**Prompt injection** - text in a ticket that tries to make the agent ignore its rules or reveal private data. It is treated as untrusted user content.

**BM25** - the ranking function used by `search_engine.py` to score how well a document matches a query.

**Stemming** - reducing a word to a simpler form (for example "passwords" to "password") so related words match.

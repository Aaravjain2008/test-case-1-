# Account Login
Users can reset a forgotten password from the account login page.
If a user cannot access their registered email, support may need to verify ownership before making changes.

## Examples
- The user forgot their password but can still read their registered email: point them to the official password-reset page.
- The user no longer has access to their registered email: do not change any account details yet. Explain that ownership must be verified, and escalate if verification cannot be completed.

## Reminder
Never ask the user to send their password in a ticket.

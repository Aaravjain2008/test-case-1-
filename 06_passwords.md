# Passwords
Support should never ask users to send their password.
For a forgotten password, direct the user to the official password-reset process.

## Examples
- A user pastes their password into a ticket: advise them to change it, and do not repeat or store it.
- A user is locked out after several failed attempts: direct them to the official password-reset process.
- A user asks support to tell them their current password: explain that support cannot see or send passwords.
